# BFD Analytics Website

> athenahealth Data View Analytics and Revenue Cycle Reporting for Physician Practices.

This repository hosts the official frontend for **BFD Analytics**, rebuilt with a Warm Editorial & Healthcare Finance Analytics color system and high-contrast, accessible typography.

## Features

- **Warm Editorial Color Schema**: Deep Slate (`#1E242B`) hero and footer surfaces, Warm Alabaster (`#F7F6F2`) alternating bands, Rich Charcoal (`#181C20`) typography, and focused Cobalt Blue (`#2563EB`) CTA accents.
- **Interactive KPI Demo**: 10 revenue cycle questions with interactive chart previews.
- **Clean Responsive Layout**: Tailored for desktop, tablet, and mobile viewports.
- **Zero Build Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript.

## Running Locally

To run the site locally:

```bash
# Using Python
python -m http.server 8080

# Open in your browser:
# http://localhost:8080
```
